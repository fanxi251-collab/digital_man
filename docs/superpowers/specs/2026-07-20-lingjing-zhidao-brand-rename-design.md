# “灵境智导”品牌名称替换设计

当前时间：2026-07-20 Asia/Shanghai

## 目标

将项目所有当前面向用户、管理员和使用者的品牌名称统一为“灵境智导”，消除 `LingJing AI`、`LINGJING AI` 等旧品牌文案，同时保持现有代码包、部署路径、数据库和浏览器数据兼容。

## 品牌规范

- 中文主品牌：`灵境智导`。
- 不再对外展示 `LingJing AI`、`LINGJING AI` 或 `灵境 AI`。
- 现有 `LJ` 图形标记继续保留。本轮只替换名称，不重新设计 Logo、图标或品牌色。
- 页面需要英文或装饰性眉题时，优先使用中文组合，如 `灵境智导 · 管理中心`，不新增未经确认的英文译名。

## 替换范围

### 游客端

- 共享侧栏品牌名称改为“灵境智导”。
- 导游页顶栏品牌、电影式开场品牌改为“灵境智导”。
- 输入提示改为“给灵境智导发送消息，例如：给我推荐灵山胜境的游玩路线”。
- 浏览器页面标题统一改为“灵境智导游客端”。
- 仍在仓库中保留的旧版游客 HTML 若包含可见品牌，也同步替换，避免回退页面重新出现旧名称。

### 管理端

- 游客分析、景点资料、知识库资料、美食推荐、游客反馈五个页面的侧栏品牌统一为“灵境智导”。
- 管理页英文眉题改为“灵境智导 · 管理中心”。
- `LJ` 标记与现有“管理后台/管理中心”辅助文字保留，不改动导航结构和业务功能。

### API 与人类可读元数据

- FastAPI 应用标题改为“灵境智导 RAG API”。
- 游客端构建提示页的浏览器标题同步替换。
- Python 包元数据中的描述字段改为“灵境智导景区 RAG 与智能体后端”，但发行包名保持 `lingjing-ai`。
- 代码包顶层说明字符串使用新品牌名称，不改变导入路径。

### 当前使用文档与评测资料

- 部署运行说明、环境要求、项目结构、评测 README 和评测数据集的人类可读标题统一使用“灵境智导”。
- 生成评测数据集和评测 CLI 的可读标题、说明同步替换，确保重新生成后不会恢复旧品牌。
- systemd 的 `Description` 可替换为新品牌，但 `User`、`Group`、`WorkingDirectory`、模块导入路径和命令不变。
- 历史设计文档、历史实施计划和 `daily-modify` 日志保持原样，避免改写历史记录。

## 必须保留的内部标识

以下名称属于兼容性契约，本轮不得替换：

- Python 包与导入路径：`lingjing_ai`。
- Python 发行包名：`lingjing-ai`。
- 项目目录及部署路径中的 `LingJing_AI`。
- 浏览器存储键：`lingjing_visitor_id`、`lingjing_current_session_id`、`lingjing_digital_human_avatar`、`lingjing.guide.intro.seen.v1`。
- Redis 缓存前缀、Neo4j 数据库名及相关环境变量值中的 `lingjing`。
- 数据集文件名、脚本默认路径和数据库文件名中的 `lingjing`。

保留这些标识可防止现有部署命令失效、Python 导入中断、缓存失联或游客历史会话被视为新数据。

## 数据流与异常处理

本轮不改变任何运行时数据流、API 路径、请求字段或响应结构。品牌文案均为静态展示或元数据：

- Vue 构建后由现有 FastAPI 路由继续提供游客页面。
- 管理端仍由现有 HTML 文件和静态资源提供。
- API 文档仅更新应用标题，不影响 OpenAPI 路径和 schema。
- 若旧浏览器仍缓存构建资源，重新构建后通过现有静态资源哈希加载新文案；管理页继续使用已有 `Cache-Control: no-store`。

## 测试策略

### 前端静态契约

- 游客端品牌、开场、导游顶栏、输入提示和页面标题均包含“灵境智导”。
- 五个管理页面均包含“灵境智导”，且不再包含 `LingJing AI` 或 `LingJing AI Admin`。
- 导航数量、激活状态和布局契约保持不变。

### 后端与元数据契约

- FastAPI `app.title` 为“灵境智导 RAG API”。
- 构建提示页和人类可读包描述使用新品牌。
- `lingjing_ai` 导入、发行包名和关键存储键保持原值。

### 仓库扫描

- 对当前运行界面、当前使用文档、评测源数据和生成脚本扫描旧品牌文案。
- 扫描排除历史设计文档、历史计划、每日修改日志、第三方依赖和构建产物。
- 允许内部技术标识继续出现，但不允许将其作为用户可见品牌展示。

### 构建与浏览器验收

- 运行前端单元测试、相关 pytest 契约和生产构建。
- 在游客端五个页面、电影式开场和管理端五个页面检查品牌名称。
- 检查浏览器标签标题、输入提示和 API 文档标题。
- 验证已有会话、数字人角色选择、游客匿名身份和缓存配置不受影响。

## 验收标准

- 当前游客端与管理端不再向用户展示任何旧品牌名称。
- 浏览器标题、API 标题、输入提示和当前使用文档统一为“灵境智导”。
- `LJ` 标记和现有视觉风格保持不变。
- Python 导入、部署路径、本地存储、Redis、Neo4j、数据库及 API 契约完全兼容。
- 历史记录未被批量改写，第三方或构建产物未被手工编辑。
