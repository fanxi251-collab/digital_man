SHARED DATA CONTRACT

同一份数据驱动两种场景

TourDefinition

id / version / durationMsstops[] / narration / controls

描述整条巡游的顺序、总时长、语音资源和控制策略。

TourStop

placeId / startMs / durationMscamera / routeEffect / storyCard

在线与离线适配器各自解释 camera，但共享站点时间和内容。

TourState

mode / elapsedMs / activeStopsceneKind / paused / takeover

这是唯一运行状态，UI 与场景只订阅它，不各自保存一套进度。

减少动态效果：取消飞行，只短淡化页面隐藏：自动暂停用户接管：先确认再停止巡游恢复在线：巡游结束后由用户决定
边界：第一阶段不缓存或打包高德地图瓦片。本地降级使用项目自有摄影背景和前端矢量覆盖物，避免依赖在线底图，也避免维护两套业务流程。
