DESIGN SECTION 01 · ARCHITECTURE

分层导演架构

核心原则：同一份巡游脚本同时驱动在线高德场景和本地降级场景；界面组件只表达状态，不直接操纵地图。

页面外壳

MapView

负责装配组件、加载地点，并保留现有路线与详情能力。

交互表达

舞台组件

  • LingjingOrb 灵境光球
  • TourTimeline 巡游时间轴
  • ScenicStoryCard 景点讲解卡
  • PersonaRouteSwitcher 画像路线切换
唯一调度中心

useTourDirector

读取本地巡游脚本，统一发出镜头、路线、光球、讲解和语音指令；暂停、跳过、接管只改变导演状态。

待机巡游暂停自由探索本地降级
统一场景指令
场景适配层

Scene Adapter

导演不知道底层是高德还是本地画面，因此两种场景可以无缝切换。

  • useAmapScene：3D 镜头、流光路线、标记事件
  • OfflineScenicStage：本地背景、SVG 路线、预制镜头
现有服务

数据与 AI

  • 景点与美食 API
  • 高德路线规划 API
  • AI 问答与个性化推荐
  • 现有语音与数字人能力
演示稳定性

本地预编排资源

经典路线、讲解文字、时间轴与离线场景全部随前端构建发布，默认巡游零等待。

共享数据契约：巡游站点只描述坐标、时长、镜头、讲解和资源；在线/离线场景各自解释同一条指令，避免维护两套故事流程。
